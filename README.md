# 🌐 Web Resume & Portfólio — Lucca Coelho

> Site-currículo interativo, moderno e de alta performance desenvolvido com HTML5 e CSS3 puro, focado em demonstrar competências práticas em Engenharia de Software e Inteligência Artificial.

---

## 📌 Sobre o Projeto

Este repositório contém o código-fonte do meu **portfólio e currículo web**. O objetivo principal é apresentar minha trajetória como estudante técnico, minha caixa de ferramentas e meus projetos práticos de forma sóbria, elegante e direta, servindo como cartão de visita profissional para oportunidades de estágio.

### 🎯 Destaques do Design e Arquitetura:
- **Zero Frameworks:** Construído 100% com HTML5 semântico e CSS3 puro (Vanilla), sem dependências de JavaScript ou bibliotecas pesadas.
- **Estética Dark/Tech:** Paleta inspirada em interfaces modernas (Preto/Grafite com destaques em Azul Elétrico).
- **Mobile-First & Responsivo:** Adaptado para uma experiência fluida em smartphones, tablets e desktops.
- **Foco em Conversão:** Botões de ação direta para WhatsApp, E-mail, GitHub e LinkedIn.

---

## 🛠️ Tecnologias Utilizadas

- **Estrutura:** HTML5 Semântico
- **Estilização:** CSS3 Moderno (Flexbox, CSS Grid, Variáveis CSS)
- **Tipografia:** Google Fonts (*Space Grotesk* e *DM Sans*)
- **Hospedagem:** Vercel
